Paola Deco - Catálogo de Eventos & CMS

Plataforma web Full Stack para la gestión y visualización de servicios de decoración. Incluye panel administrativo seguro, gestión de imágenes y sistema de cotización directa.


Problema

La empresa necesitaba digitalizar su portafolio físico, centralizar la información de sus servicios y agilizar el proceso de cotización que se realizaba manualmente.


Solución

Desarrollo de una aplicación web a medida con un catálogo público interactivo (filtros, búsqueda) y un dashboard administrativo privado (CMS) para gestionar inventario, usuarios y configuraciones del negocio en tiempo real, integrando WhatsApp para el cierre de ventas. (Proyecto desarrollado como MVP utilizando técnicas de Vibe Coding e IA para la generación acelerada del código base).


Tecnologías:

React + Vite Node.js & Express MongoDB (Atlas) Tailwind CSSr Cloudinary (Gestión de Imágenes)
